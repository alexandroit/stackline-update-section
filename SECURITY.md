# Security

Report suspected vulnerabilities privately through the security-advisory form
for `alexandroit/stackline-update-section` on GitHub. Do not open a public issue
for an undisclosed vulnerability.

Include the affected version, reproduction, impact, and any suggested fix.
Maintainers will acknowledge a complete report as soon as practical and will
coordinate disclosure after a fix is available.

The supported line is the latest published major version. This package has no
runtime, peer, or optional dependencies; development tooling is not included
in the published artifact.
