Narrow compatibility corrections

Metadata tells the truth.

Normal upstream output remains unchanged. The maintained package corrects the documented parser defects and one scale failure.

  • Inclusive end index. endIdx always identifies the last replaced input line.
  • Truthful end flag. hasEnd is true only when the end matcher succeeds.
  • Ordered markers. End markers before the selected start are observed by callbacks but do not form crossed ranges.
  • Large sections. Insertion avoids argument-count limits from Function.apply.
